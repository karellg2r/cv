# Karell Girdary — CV en ligne

Site statique (un seul fichier `index.html`, sans dépendance à installer).

## Mise en ligne avec GitHub Pages
1. Créer un dépôt public sur GitHub (ex. `cv`, ou `karellgirdary.github.io` pour une adresse sans sous-dossier).
2. Déposer `index.html` (et ce README) à la racine du dépôt.
3. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
4. Le site est disponible en 1 à 2 minutes sur `https://<pseudo>.github.io/<nom-du-depot>/`.

## Modifier le contenu
Tout le texte se trouve dans l'objet `CONTENT` en haut du script de `index.html`
(expériences, certifications, langues, coordonnées). Les certifications se trouvent dans `certifications`.
